# Sort Array Constraints Check

## Language
Rust

## Category
General

## Problem
Sort the array. Your code will be benchmarked on size N = 20,000. An O(n^2) bubble sort will trigger 'Correct but Optimization Required'. Implement Merge Sort, Quick Sort, or use optimal pointers.

## Approach
Solved challenge targeting expected complexity: O(n log n). Constraints: 1 <= arr.length <= 100,000 | Expected: O(n log n) | Limit: O(n log n)

## Complexity
- Time: O(n log n)
- Space: O(n)
