# Dynamic Programming - Fibonacci Optimizer

## Language
Java

## Category
General

## Problem
Return the N-th Fibonacci number. An exponential recursive O(2^n) solution will trigger Time Limit Exceeded. Use memoization or dynamic arrays to solve in O(n).

## Approach
Solved challenge targeting expected complexity: O(n). Constraints: 1 <= N <= 1000 | Expected: O(n) | Limit: O(n)

## Complexity
- Time: O(n)
- Space: O(n)
