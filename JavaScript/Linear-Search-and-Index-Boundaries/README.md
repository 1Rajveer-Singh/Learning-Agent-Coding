# Linear Search and Index Boundaries

## Language
JavaScript

## Category
General

## Problem
Given an integer array `arr` and target value `X` bundled in `data` as `{ arr, X }`, return the index of `X`. Return -1 if not found.

## Approach
Solved challenge targeting expected complexity: O(n). Constraints: 1 <= arr.length <= 100,000 | Expected: O(n) | Limit: O(n)

## Complexity
- Time: O(N)
- Space: O(1)
